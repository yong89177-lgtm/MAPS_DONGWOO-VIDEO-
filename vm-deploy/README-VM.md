# VM 서버 배포 안내

이 폴더(`vm-deploy/`)는 VM 서버(10.34.220.251)에 그대로 복사해서 사용하는 배포용 폴더입니다.
`node_modules/`는 포함되어 있지 않으며, VM에서 `vm-install.bat` 실행 시 새로 설치됩니다.

## 최초 1회 (VM에 폴더를 옮긴 직후)

1. 이 폴더 전체를 VM으로 복사합니다 (RDP 화면 복사, 공유폴더, USB 등 편한 방법 사용).
2. `vm-install.bat`을 실행합니다.
   - Node.js 설치 여부 확인
   - `npm install`로 의존성 설치
   - `.env` 파일이 없으면 `.env.example`을 복사해서 생성 (이후 `ADMIN_KEY`를 실제 값으로 반드시 변경)
   - Windows 방화벽에 3000번 포트 인바운드 허용 규칙 추가 (관리자 권한으로 실행 권장)

## 서버 실행

`vm-start.bat`을 실행하면 서버가 시작되고, 다음 주소로 접속할 수 있습니다.

```
http://10.34.220.251:3000
```

기존 로컬 PC용 `run.bat`과 동일하게, **콘솔창을 열어둔 상태에서만 서버가 동작**합니다.
창을 닫거나 Ctrl+C를 누르면 서버가 종료됩니다.

## 수정사항 반영 방법

- `public/` 안의 HTML/CSS/JS 파일만 수정한 경우: 서버 재시작 없이 파일만 덮어쓰면 바로 반영됩니다 (브라우저 새로고침).
- `server/` 안의 코드나 `package.json`(의존성)을 수정한 경우: 콘솔창에서 `Ctrl+C`로 서버를 끈 뒤 `vm-start.bat`을 다시 실행해야 반영됩니다.
- 의존성이 바뀐 경우(`package.json` 변경)는 `vm-install.bat`을 다시 실행해서 `npm install`을 먼저 해줘야 합니다.

## 참고

- 이 폴더는 로컬 리포지토리의 `data/db.json`, `uploads/`를 복사해서 만들어졌습니다. 이후 VM과 로컬 데이터는 서로 자동 동기화되지 않으니, 필요하면 수동으로 파일을 다시 복사해야 합니다.
- 네트워크/보안그룹(VM이 속한 클라우드 방화벽 등)에서 3000번 포트가 막혀 있다면 `vm-install.bat`의 Windows 방화벽 설정만으로는 접속이 안 될 수 있습니다. 이 부분은 별도로 확인이 필요합니다.
