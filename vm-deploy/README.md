# MAPS — AI Agent 마켓

메인 화면(`MAPS 영상버전 (김동우 선임) 2 (1).html`, `/` 경로)에서 `＋ AI Agent 등록` 버튼을 눌러
HTML 파일 기반 AI 에이전트를 등록 요청하고, 관리자가 **1차(IT) 승인 → 2차(적절성) 승인**을
거치면 카테고리별 영역에 카드가 노출됩니다. 카드를 클릭하면 등록 시 업로드한 HTML 파일이
새 탭에서 그 자리에 실행됩니다.

## 실행 방법

```bash
npm install
cp .env.example .env   # ADMIN_ID/ADMIN_PASSWORD(1차), ADMIN2_ID/ADMIN2_PASSWORD(2차)를 변경
npm start               # http://localhost:3000
```

개발 중에는 `npm run dev` (nodemon)로 실행하면 서버 코드 변경 시 자동 재시작됩니다.

- 메인 페이지: `/` — 위 HTML 파일을 그대로 서빙합니다.
- 로그인은 메인 페이지 우측 상단 "로그인"에서 진행합니다(회원가입은 관리자 승인 후 사용 가능).

## 등록 → 승인 → 노출 흐름

1. 사용자가 메인 화면에서 `＋ AI Agent 등록`을 눌러 이름/요청자/기술그룹/팀/설명/카테고리와
   (선택) HTML 파일을 입력하고 "요청 보내기"를 누르면 `POST /api/dash-request`로 전송되어
   `pending`(1차 IT 검토 대기) 상태로 저장됩니다. 로그인 없이도 등록할 수 있습니다.
2. **1차(IT) 승인**은 `.env`의 `ADMIN_ID` 계정으로 로그인해야만 처리할 수 있습니다
   (관리자 콘솔 종 모양 아이콘 → 승인 관리 탭). 승인하면 `it_approved` 상태가 됩니다.
3. **2차(적절성) 승인**은 `ADMIN_ID`가 아닌 다른 관리자 계정(`.env`의 `ADMIN2_ID` 등)만 처리할
   수 있습니다. 승인하면 `approved` 상태가 되고, 요청한 카테고리(들) 중 첫 번째 항목의 컬럼에
   카드가 자동으로 추가됩니다 — 일치하는 카테고리가 없으면 새 카테고리 컬럼이 만들어지고,
   선택한 카테고리가 없으면 "공통 및 루틴 업무"에 들어갑니다. 두 단계 중 어디서든 반려가
   가능하며 사유를 입력할 수 있습니다.
4. 메인 화면 "카테고리별 AI Agent" 영역에서 카드를 클릭하면 `GET /api/dash-file?id=...`로
   승인된 HTML 파일이 새 탭에서 열려 그 자리에서 실행됩니다.

## 데이터 저장

`data/` 폴더에 JSON 파일로 저장합니다.
- `data/dashboards.json`: 카테고리별 카드 카탈로그(메인 화면이 그대로 읽어가는 데이터). 최초
  구성이 커밋되어 있고, 2차 승인 시 서버가 이 파일에 카드를 추가합니다.
- `data/accounts.json`, `data/signup-requests.json`, `data/dash-requests.json`: 계정/가입
  신청/등록 요청 데이터. 비밀번호 해시 등 민감정보가 포함되므로 `.gitignore`에 등록되어
  있으며, 서버를 처음 실행하면 `.env`의 관리자 계정으로 자동 생성됩니다.

업로드된 HTML 파일은 `uploads/dash-requests/<요청 id>.html` 형태로 저장됩니다. 소규모
데모/내부용으로 충분하지만, 운영 규모가 커지면 실제 데이터베이스(PostgreSQL 등)와 오브젝트
스토리지로 교체하는 것을 권장합니다.

## 인증

메인 화면은 아이디/비밀번호 로그인(쿠키 세션) 방식입니다. `.env`에 최초 부팅 시 자동 생성될
관리자 계정 2개(`ADMIN_ID`/`ADMIN_PASSWORD`, `ADMIN2_ID`/`ADMIN2_PASSWORD`)를 설정해야
1차·2차 승인을 각각 다른 계정으로 진행할 수 있습니다. 일반 계정은 메인 화면에서 회원가입 신청
후 관리자 승인을 받아 사용합니다.

`public/`, `server/routes/agents.js`는 이전에 별도로 만들어졌던 프로토타입(간이 카드 마켓)
UI로, 실제 메인 화면과는 무관하게 `/index.html`, `/admin.html`에 그대로 남아 있습니다.

## 보안 참고

- 등록 시 첨부 가능한 HTML은 4MB로 제한하고 `.html`/`.htm` 확장자만 허용합니다.
- 2차 승인 전(또는 반려/취소된) 요청의 HTML은 공개 라우트(`/api/dash-file`)로 열람할 수
  없습니다(관리자 전용 `/api/req-file`만 상태와 무관하게 열람 가능).
- 업로드된 HTML은 사용자가 직접 작성한 콘텐츠이므로, `/api/dash-file`·`/api/req-file` 응답에
  `Content-Security-Policy: sandbox` 헤더를 적용해 — 새 탭으로 직접 열더라도 — iframe
  sandbox와 동등하게 스크립트/폼/팝업 외의 권한(쿠키·로컬스토리지 접근, 동일 출처 API 호출 등)을
  차단합니다.
